# 问题台账：带位置、原因、修正方案、验证条件

约定：位置 `09:67-75` 表示 `09_*.md` 第67~75行。P0=正确性/架构阻断；P1=生产化缺口；P2=后续质量完善。没有已经编译验证的软件缺陷结论。

## P0 — 10项

### A001 多规格共享渲染边界错误
- **证据位置**：`07:66-72;09:67-75;13:109-114;40:51-68`
- **问题**：统一时间点并集不等于不同 Profile 的 RGBA 可共享；不同 canvas、renderer、HDR、字体环境、storage/PAR 的结果通常不同。
- **最佳修正**：引入 RenderGroupKey=(script transform,renderer id+version,canvas,storage,PAR,font bundle,color policy,animation policy)，每组内部取时间采样并集；共享 AST/时间轴/可证明相同的 RGBA，跨组不共享帧。
- **验收**：720/1080/2160与libass/VSFilter输出不错误缓存；相同组 BDN+SUP只渲一次。

### A002 HDR亮度算法缺失
- **证据位置**：`11:1-37;05:24-31;36:11-31`
- **问题**：只有“百分比/203 nit”概念，没有色域、EOTF/OETF、输入编码假设、白电平映射公式、alpha与明度边界等。ASS 本身不能保证播放端真实 nit。
- **最佳修正**：明确模式 1 字节级 legacy dim；模式2 在指定假设下做 sRGB解码->线性亮度目标->sRGB编码并量化；HDR/PQ目标需将最终视频合成链作为前置条件；所有模式保留alpha并追踪内联颜色和\t嵌套颜色。
- **验收**：白灰彩/描边/动态变色完整单元黄金样本+跨播放器视觉对比；UI不得承诺绝对nit。

### A003 PGS颜色与时序验收的形式化规范缺失
- **证据位置**：`13:8-120;10:20-28;25:15-19`
- **问题**：有字段清单却没有完整字节契约、epoch/display-set状态图、timestamp wrap/排序/允许FPS矩阵、来源规范可审计表；Strict尚不可复现。
- **最佳修正**：分离结构解析验证、显示时序验证、buffer模拟器、设备实验；固定含PDS 5字节调色板条目(index,Y,Cr,Cb,alpha)的参考向量；明确90k tick/32位封装、DTS策略和分片。
- **验收**：与FFmpeg/其他独立decoder双向解码，golden逐段断言，错误码可定位offset。

### A004 WBS DAG 缺节点且依赖方向错误
- **证据位置**：`27:1-69;26:1-39`
- **问题**：RenderTimelinePlanner、encoding、renderer能力检测、process runner、color matrix、字体许可等没有任务ID；Strict validator依赖Advanced Author不合理。
- **最佳修正**：新增 R040 Timeline、C005 output color policy、J006 Planner DAG、V001 structural validator、V002 timeline、V003 buffer、A000 external process runner等；Strict validator的单项可先于Advanced Author开发。
- **验收**：机器检查任务ID唯一、所有依赖均存在、无环、每阶段有gate/test/交付件。

### A005 完整16:9硬规则有例外冲突
- **证据位置**：`00:17-23;09:3-11;09:86-97;32:12-14`
- **问题**：09允许“实验性非16:9画布”，但用户对特效输出要求完整16:9；原始ASS的PlayRes不应被视为强制16:9。
- **最佳修正**：特殊字幕输出目标画布仅允许16:9；原始脚本PlayRes/LayoutRes保真，不用强制改写源；其他长宽比单独作为非特效/不支持实验域并与正式工作流分离。
- **验收**：2.39:1黑边、PlayRes非16:9输入在全画幅16:9目标上保持正确位置。

### A006 字节级ASS保真与自动改写规则未固化
- **证据位置**：`08:5-18;14:3-10;25:3-4`
- **问题**：未知tag保留已规定，但源编码、BOM/换行、注释顺序、字段动态映射、损坏输入恢复、内联\t和\rStyle等语义没有可执行契约。
- **最佳修正**：建立 TokenSpan AST 和ByteRangePatch；源文件无修改时逐字节等价；变换仅改已识别 token；不支持的未知颜色扩展警告而不擅改。
- **验收**：真实ASS corpus逐字节Roundtrip(无变换)及字段差异白名单；编码异常拒绝隐式有损替换。

### A007 特效渲染兼容清单及回退规则不足
- **证据位置**：`12:33-44;12:64-112;24:20-21`
- **问题**：CSRI/VS/AviSynth接口识别正确，但没有实际测试的provider二进制/导出表/调用约定矩阵；“自动选择”易给出错误兼容承诺。
- **最佳修正**：Phase0对每个支持的provider锁文件SHA和x86/x64；CapabilityManifest列 APIs/输出格式/字体加载/线程安全/ANSI限制；无合适provider则失败或显式用户确认fallback。
- **验收**：每个provider独立宿主进程运行smoke + differential + crash isolation测试。

### A008 严格兼容等级夸大风险
- **证据位置**：`02:49-53;13:87-120;25:19`
- **问题**：“Level5+device corpus通过→Strict”没有定义真实硬件覆盖、认证机构、正式约束引用；样本库通过不代表所有设备必然兼容。
- **最佳修正**：UI采用“通过本工具严格校验（模型/版本）”；仅经过真实机型复验者标“实机验证”；禁止“认证/保证所有蓝光设备”。
- **验收**：报告列validator版本、profile、测试设备/固件/样本及已知未覆盖限制。

### A009 安全：独立进程不等于沙箱
- **证据位置**：`12:45-55;23:17-21`
- **问题**：Job Object主要提供进程树资源管理，并不阻断第三方恶意DLL对用户文件/网络的访问。
- **最佳修正**：将renderer隔离明确为崩溃隔离；评估restricted token/low integrity/AppContainer及插件资源限制和权限最小化；不可信DLL须显式用户同意。
- **验收**：恶意plugin访问非授权路径、外联、生成子进程等威胁模型与可执行测试。

### A010 质量门槛未量化
- **证据位置**：`24:1-75;25:1-28`
- **问题**：只有AT-ID一行说明，没有 fixture、输入/预置、步骤、期望数值和容差；无法作为验收测试脚本。
- **最佳修正**：定义每项 TestCase={fixture,setup,steps,expected,oracle,tolerance,env,artifact,owner}; 按P0/P1 release gate排序。
- **验收**：CI能逐条产生机器可读测试结果、视觉diff报告和基准版本。

### A012 CLI与进程产品命名冲突

- **验收**：生成产物清单与CLI --version所有名字一致。

### A013 Windows 10生命周期策略过时
- **证据位置**：`00:1-8;06:15-19;24:35-36;28:1-38`
- **问题**：Win10 22H2已于2025-10-14结束常规支持。文件视Win10/Win11为等价发布基线而未提ESU/老系统维护义务。
- **最佳修正**：Windows11为主要受支持系统，Win10 22H2设兼容/尽力支持并说明ESU；如坚持全面支持，维护独立测试与安全告知。

### A014 PGS fast-path“无损”措辞不准确
- **证据位置**：`02:42-47;13:23-43;05:60-65`
- **问题**：保留ODS仅能保证不重编码位图；调色板、位置、时间修改当然会改变视觉/播放表现，不应称为总体无损。
- **最佳修正**：统一UI标签“位图不重编码”；验证ODS字节不变仅作为必要条件，另检查其它segment副作用。
- **验收**：Loss report将结构保真、视觉变化和符合性分成独立维度。

### A015 多输出预设缺继承/冲突处理
- **证据位置**：`09:55-66;15:1-36;36:10-41`

- **最佳修正**：定义强类型JsonSchema/TOML schema、字段优先级及迁移、dry-run collision planner，单个job所有输出目标唯一，源文件默认不可覆盖。
- **验收**：随机组合Profile property tests；路径冲突预检、非法/保留名、不同大小写碰撞。

### A016 输出事务跨卷与多文件目录缺口

- **验收**：断电/磁盘满/杀进程模拟不得留下冒充成功的产物，旧文件完整保留。

### A017 ASS→SRT剥离语义不足
- **证据位置**：`14:3-10;08:43-51`
- **问题**：\N/\n/\h、drawing文本、k标签、嵌套事件、重叠对白、重号等无法靠“remove tags”保证语义。

### A018 编码探测与原始字节保存策略缺失
- **证据位置**：`05:10-22;08:8-18;14:6-7`

- **最佳修正**：探测仅给候选及置信度；用户可选解码并预览异常数；不能默认replace invalid bytes后覆写。
- **验收**：中日韩+混合BOM/乱码corpus，保存后字段未修改处等价。

### A019 字体打包缺字体授权限制
- **证据位置**：`17:1-83;21:1-50`

### A020 PGS帧率/视频规范与自定义输出合规矩阵不完整

### A021 SUP原始色彩空间推定过强

- **最佳修正**：要求用户指定源/目标颜色策略或从关联视频有证据推断，记录置信度；不明时禁用“精确HDR映射”，保留百分比实验模式。

### A022 HFR采样与降采样算法不可执行
- **证据位置**：`09:67-75;12:87-101;13:109-114`
- **问题**：“事件精确边界+逐帧/自适应”没有给sampling条件、静态检测、最大预算、帧尾闭区间和降帧准则，动态特效将性能爆炸。
- **最佳修正**：定义时间域为半开区间[start,end)，按输出分组，帧网格+可观察边界；动态帧率降采样用像素差/可见保持时间/带宽预算约束，默认只采取保真路径。
- **验收**：动态移动、\t、karaoke在12/24/60fps的视觉误差和速度基准。

### A023 MKV替换轨道流程缺命令级契约

### A026 外部依赖缺可复现锁与获取策略

- **问题**：“Safe Normalize”未区分排序、重复删除、换行、最短时长修正、强制字幕标记等可能改变观看语义的操作。
- **最佳修正**：分为Byte-safe / Semantic-preserving / Content-altering三级；后两级默认关闭并有预览、可还原策略。
- **验收**：自动操作前后event/text/style/PTS hash维度报告；每项可单独回退。

## P2 — 6项

### A033 自用与公开分发目标边界缺失
- **证据位置**：`01:1-83;21:1-50;28:1-38`
- **问题**：产品说个人使用，不等于永不公开分发；是否闭源/开源/公开下载决定各依赖许可、签名/更新、法务安排。
- **最佳修正**：在ADR新增Licensing/Distribution Goal：private only / public open source / public proprietary，临时默认不要捆绑GPL组件。
- **验收**：发布检查表按三种分发策略生成不同gate。

### A034 字库/动画基准缺合法语料与可分享边界
- **证据位置**：`17:45-61;24:1-75`
- **问题**：真实动漫 ASS、商业字体和蓝光PGS参考可能受版权限制；如果测试样本直接打包公开，存在许可风险。
- **最佳修正**：Corpus分公开合成fixture/授权真实fixture/本地private fixture；公开测试只放权属明确材料与最小合成向量。
- **验收**：仓库manifest明确来源/许可证/是否可公开分发。

### A035 应用视觉品牌/设计系统未规范
- **证据位置**：`04:1-63;05:1-110;35:1-63`
- **问题**：有页面和系统色切换，但缺Design tokens、层级、间距、Typography、状态色、图标、密度、动画减弱规则、窗口调整行为。
- **最佳修正**：补DESIGN_SYSTEM和COMPONENT_CATALOG；克制动效，以性能与可诊断性为先。
- **验收**：设计token映射所有页面/主题；视觉回归截图审核。

### A036 变更追踪只有版本日志
- **证据位置**：`31:1-69;34:1-14;41:1-12`
- **问题**：没有单一需求ID->设计->代码->测试关联，不能证明“所有UI选项都实现”；变更日志没有每项修复owner和验收。
- **最佳修正**：建立Traceability Matrix，REQ-xxx→UI control→Config→Stage→WBS→Test→Release；状态Proposal/Accepted/Implemented/Verified。
- **验收**：自动扫描所有正式UI动作可追到至少一个测试与处理stage。

### A037 VFR和字幕FPS概念提醒可再强化
- **证据位置**：`10:1-37;05:33-39`
- **问题**：文档合理地区分speed/snap但未定义22.976? 小数显示与真分数，VFR帧时间映射、多个视频段变速精度。
- **最佳修正**：FPS显示分数+友好小数；时间映射用i128防溢出，Snap必须给frame time map；未获得VFR timecode map时拒绝“真实逐帧贴合”。
- **验收**：2小时23.976与24累计漂移、VFR剪辑、33-bit边界等特定fixture测试。

### A038 ASS合并的样式引用不完整
- **证据位置**：`14:24-26;08:8-18`
- **问题**：Style重名处理写了Dialogue.Style，却没提内联\rStyle、Script Info依赖、Layer冲突、Fonts/Graphics附件重名。
- **最佳修正**：合并时建立per-source StyleMap，在Event.Style和Override \rName中双向替换；多脚本属性冲突生成报告/拒绝自动合并。
- **验收**：两个ASS共享Style名但字体不同/含\rStyle时合并渲染视觉等价。
