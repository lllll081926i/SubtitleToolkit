# 文档导航

## 文档优先级

1. [当前状态](STATUS.md)记录现有实现、未完成范围和最近一次实际核验。
2. `specs/` 定义目标行为；规格条目不等于功能已实现。
3. `planning/` 记录后续次序与验收门槛；依赖外部裁决的项目不能阻塞无关工作。
4. `history/` 保存旧状态和旧门阶记录，只说明当时结论。
5. [本轮审查](reviews/2026-10-07.md)记录代码、规划与文档的审查及修正。
