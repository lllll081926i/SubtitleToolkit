# Windows UI 信息架构规范（纯 Rust 原生 GUI）

本文档定义 SubtitleToolkit-RS 桌面客户端的信息架构与工作区层次。须联合阅读 [05 UI 页面规格](05_UI_SCREEN_SPEC.md) 与 [35 UI 交互规范](35_UI_STATE_INTERACTION.md)。

---

## 1. 技术选型与运行形态
- **UI 框架**：纯 Rust + Iced 原生渲染管线（wgpu / tiny-skia），不使用 Webview/Electron。
- **窗口形态**：单主窗口响应式三栏工作台，设计基准尺寸 1440×900，最小可用尺寸 1100×720。
- **文件选择**：Windows 原生对话框（`rfd` / `IFileDialog`），支持 UNC 路径与长路径。
- **拖拽支持**：支持 Windows Explorer 文件（`.ass`, `.srt`, `.sup`, `.mkv`, `.mp4`）及文件夹直接拖放。
- **主题外观**：深色与浅色自适应 Windows 11 系统设置，提供高对比度与跟随系统开关。

## 2. 现代三栏一体化主窗口架构

区别于早期将功能机械切分为 10 个独立平铺平面的设计，现代化信息架构采用**流式三栏一体化工作区**：

## 3. 信息流动模型：从输入到多输出管道

系统的核心数据流由左至右线性流动：
1. **输入阶段（左栏）**：用户导入一个或多个字幕文件，底层快速完成格式嗅探（`format-detect`）与元数据解析；
2. **预览与检验阶段（中栏）**：选定任一输入文件，中栏立刻展示其实际渲染画面，并列出字体健康状态（完全命中、部分缺字、完全缺失）；
3. **变换与定制阶段（右栏）**：用户配置目标 Profile 列表（例如：Profile A 为 1080p SDR 蓝光 BDN，Profile B 为 2160p 4K HDR SUP，Profile C 为纯文本 SRT）；
4. **执行与落盘阶段（底栏）**：点击“开始队列”，生成不可变任务快照 `JobSnapshot` 送入后台 `task-engine` 并发执行，底层通过事务机制原子落盘。

## 4. 辅助视窗与设置层级

为保持主界面清爽高效，非高频操作收纳为弹层与侧边抽屉：

- **预设管理器 (Preset Drawer)**：
  - 保存/加载整套 Profile 组合方案（如 `4K蓝光+外挂SRT双出方案`）；
  - 支持导入与导出 JSON 配置。
- **环境自检 (Doctor Dialog)**：
  - 对应 CLI 的 `doctor` 命令，可视化展示本机的 `libass` 运行库版本与哈希、`ffprobe` 路径、可写目录权限与字体库缓存状态。
- **系统设置 (Settings Dialog)**：
  - 默认输出目录与命名模板（如 `{stem}.{profile}.{ext}`）；
  - 默认覆盖策略（默认重命名避让，防止覆盖已有文件）；
  - 渲染线程并发数限制与日志详细级别。
